# Certificates Folder

This folder contains all certificate PDFs to be showcased on the portfolio.

## File Naming Convention

Use descriptive, lowercase names with hyphens:
- `ml-internship-vaishnav.pdf`
- `react-certification.pdf`
- `aws-cloud-practitioner.pdf`

## How to Add Certificates

1. Place your PDF files in this folder
2. Update the certificates data in `src/data/certificates.ts` (or similar)
3. Reference them in components using `/certificates/filename.pdf`
